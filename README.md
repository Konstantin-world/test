# Мозг на максимум

> *«Не играй в тренировку. Живи с тренированным мозгом.»*

Русскоязычное когнитивно-тренировочное приложение: 8 когнитивных доменов,
адаптивная сложность с целевой точностью 79.4%, интеграция контента книги
и канала, классические головоломки и прозрачная аналитика.

Позиционирование — **«умный баланс»**: научная дисциплина BrainHQ, игровая
лёгкость Peak, практическая польза Elevate и глубина книги. Без клинической
сухости и без агрессивных микротранзакций.

## Проверка

Контент валидируется исполняемым скриптом, а не ревью «на глаз»:

```bash
node tools/validate-content.mjs           # проверка, exit 1 при ошибке
node tools/validate-content.mjs --report  # + таблица кривых сложности
```

Что проверяется: схема полей, целостность ссылок на домены, границы параметров
сложности, наличие научного обоснования у каждого упражнения, а также продуктовые
инварианты — квота MVP «10–12 упражнений» из дорожной карты, покрытие всех
8 доменов, онбординг на 4 домена, собираемость короткой сессии.

## Каталог: 60 упражнений, 13 архетипов

Каталог брифа (50 тренировок) сведён с базовым слоем раздела 1.7 (Шульте,
классический Струп, task-switching) и каталогом v1.0.0 (судоку, анаграммы,
«слова из слова», «10 способов использования», «Истории», RSVP). Дубликаты
схлопнуты, пересечения помечены в `meta.duplicatesFlagged`.

```
по доменам    spatial_reasoning 13 · memory 12 · number_sense 9 · logic 8
              attention 7 · creativity 4 · language 3 · cognitive_flexibility 2
              processing_speed 1  ← перекос, см. open-questions №20
по архетипам  single_choice 19 · stateful_board 11 · numeric_input 5
              sequence_recall 5 · timed_field 5 · остальные ≤3
по контенту   generated 48 · authored 8 · external 3
доказательность  paradigmValidity A=31 B=22 C=6 · transferEvidence A=2 B=34 C=23
```

**Только два упражнения из 60 имеют доказанный перенос** (`transferEvidence = A`):
`spaced_repetition` и `reaction_field`. Это не повод их скрывать — это и есть
научная честность, заявленная как отличие от конкурентов.

## Научная позиция

**Утверждаем:** регулярные тренировки улучшают выполнение самих тренируемых
задач и поддерживают когнитивный тонус.

**Не утверждаем:** что приложение «лечит» или гарантирует перенос на все
аспекты повседневной жизни — этот перенос остаётся научно дискуссионным.

Каждое упражнение в каталоге несёт **две раздельные оценки** доказательности:
`paradigmValidity` (признана ли сама парадигма) и `transferEvidence`
(доказан ли перенос). Их смешивают почти все конкуренты — например, парадигма
Струпа безупречна (`A`), а перенос тренировки на исполнительный контроль
умеренный (`B`), а у «Найди пару» оба показателя низкие.

> Приложение не является медицинским изделием и не заменяет консультацию специалиста.
